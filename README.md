# Пульс — медицина от гимназии до врача

Интерактивная платформа для изучения медицины на русском языке: от устройства клетки и первой помощи для школьников до ЭКГ, сепсиса, расширенной реанимации и доказательной медицины для студентов-клиницистов и врачей.

Без сборки, без сервера и без зависимостей: чистый HTML, CSS и JavaScript. Прогресс хранится в браузере (`localStorage`).

### Уровни

0. **Тело человека** (школа и гимназия) — что такое медицина, клетка, ткани, сердце, кровь, дыхание, пищеварение, нервная система, иммунитет и вакцины, гены, первая помощь, здоровый образ жизни, кожа и кости, гормоны и взросление, мозг и сон, зависимости, инфекции, психическое здоровье.
1. **Нормальный организм** (1–2 курс) — анатомическая терминология, опорно-двигательный аппарат, сердце и гемодинамика, дыхание, почки, кислотно-основное равновесие, нейрофизиология, клиническая неврология, эндокринология, биохимия, ЖКТ и печень.
2. **Механизмы болезни** (2–3 курс) — повреждение клетки, воспаление, тромбоз и шок, опухоли, иммунология, бактерии, вирусы и грибы, антибиотики, фармакокинетика и фармакодинамика.
3. **Клинические навыки** (3–4 курс) — анамнез, осмотр, витальные функции и NEWS2, ОАК, биохимия и электролиты, ЭКГ, визуализация, клиническое мышление, документация.
4. **Клиническая медицина** (4–6 курс) — 26 уроков: гипертензия, ОКС, СН, ФП, астма и ХОБЛ, пневмония, диабет, щитовидная железа и надпочечники, почки, гастроэнтерология, острый живот, инсульт, тромбозы, инфекции, педиатрия, акушерство, онкология, психиатрия для любого врача, ревматология, гематология, дерматология, неврология, урология, глаз и ЛОР, гериатрия, травма.
5. **Врач у постели больного** — ABCDE, ALS, шок, анафилаксия, инфузии и электролиты, обезболивание, доказательная медицина, этика и право, безопасность пациента, трудные разговоры, паллиативная помощь, профессиональное здоровье, токсикология, переливание крови, кислород и дыхательная недостаточность, антибиотики на практике, периоперационная медицина.

Рекомендации отражают европейские руководства (ERC 2021, ESC 2023–2024, GINA, GOLD, KDIGO, Surviving Sepsis Campaign). Материал упрощён для обучения; дозы и пороги сверяйте с действующими местными протоколами.

## Запуск

Откройте `index.html` в браузере — всё. Сервер не нужен.

Публикация через GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root. Файл `.nojekyll` уже есть.

Один самодостаточный файл (удобно отправить или открыть офлайн):

```bash
node tools/build-single.js      # → dist/pulse.html
```

Проверка целостности контента (id, ответы, ссылки, термины):

```bash
node tools/validate.js
```

## Логотип и превью для соцсетей

Знак — белый медицинский крест, через который проходит коралловая линия ЭКГ, на «хирургическом зелёном» фоне. Хирургический зелёный — цвет операционной формы: он дополнителен к красному цвету крови и гасит остаточные образы у хирурга.

Файлы в `assets/img/`: `og-image.png` (превью 1200×630 для Telegram, WhatsApp, VK, Facebook, X, LinkedIn, Discord), `logo.png`, `favicon.svg`, иконки. Мета-теги Open Graph и Twitter в `index.html` указывают на `https://prov-ori.github.io/med/`. Если сайт будет жить по другому адресу, замените этот адрес во всех тегах `og:*`, `twitter:*`, `vk:image` и `canonical` — соцсети принимают только абсолютные ссылки.

Перегенерировать изображения (нужен Playwright):

```bash
node tools/make-brand.js
```
